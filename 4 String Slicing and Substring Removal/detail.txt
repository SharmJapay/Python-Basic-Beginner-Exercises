Practice Problem: Write a function to remove characters from a string starting from index 0 up to n or starting from last index up to -n, and then return a new string.

Exercise Purpose: This exercise demonstrates how to truncate data strings, a common data-cleaning task.

Given Input:
remove_chars("Coding with Python is fun", 4, 'start')
remove_chars("Coding with Python is fun", 2, 'end')

Expected Output:
The new text is 'ng with Python is fun'
The new text is 'Coding with Python is f'
